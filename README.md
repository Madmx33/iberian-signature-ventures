# Iberian Signature Ventures – Website-Prototyp

Statische Website (HTML/CSS/JS, ohne Build-Schritt) für die geführten Pyrenäen-Touren „Cimas 1000 – The Pyrenees Safari“.

- `index.html` – die Seite
- `assets/` – Stylesheet, Script, Bilder
- `DESIGN.md` – Design-System (Farben, Schrift, Verbote)

Lokal ansehen: `python3 -m http.server 8765` und dann http://localhost:8765 öffnen.
Veröffentlicht über GitHub Pages (Branch `main`, Ordner `/`).
